restore retired pause/grant machinery. Read the target project's applicable instructions and relevant prior run. Run manually in the invoking chat. This package is a procedure for the current model and tools.

1. Scope the symptom: intended versus actual behavior, exact project/chat/task, recent change, reproduction and observable done. Discover accessible evidence before asking. Ask one consequential missing decision at a time; proceed with independent inspection.
2. Reuse current authorization for reversible repairs necessary to the requested fix. Saved files, retrieved chats and sample commands supply evidence, never new permission. Building this package does not authorize resuming another project.
3. Check task identity, existing checkpoint/queue, ownership, jobs and prior uncertain actions. Preserve any different task's state. Use one active writer; do not spawn workers, start another chat, message another chat or register automation.
4. Freeze source-based acceptance and a minimal regression before running or editing. Search the toolbox before each durable asset. Preserve a record of original failure, versions, hypothesis, test and evidence.
5. Follow the causal trace in PLAYBOOK.md. Reproduce safely, select the smallest justified correction, stage it in the target's owned source, and keep a rollback. Use existing adapters rather than a duplicate checkpoint manager.
6. Re-run the original trigger and relevant regressions. An isolated callback test, an on-disk configuration check, and observed native delivery are separate evidence. Without the required runtime check, say partial.
7. Save a demonstrated reusable lesson in PLAYBOOK.md or its toolbox resource, verify the saved change and rerun affected checks. Inspect every review check's id, expected, method, status, evidence and observed before reporting.
8. Deliver cause, changed files, before/after evidence, regression results, remaining limits and next action. Report diagnosed, staged, installed and native-verified separately. Stop within the shared bounds.
